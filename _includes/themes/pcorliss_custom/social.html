{% comment %} Profile links. Icon-only, so each link carries an accessible name and the glyph itself is hidden from assistive tech. Mastodon and Bluesky are inline SVG (see _data/icons.yml) instead of Font Awesome glyphs: the 4.7 stylesheet this site loads has no such icon for either. rel="me" on the Mastodon link is functional, not decoration - Mastodon fetches the URL from your profile and looks for an or whose rel contains "me" and whose href matches its canonical profile URL exactly apart from case, so the value in _config.yml has to be spelled right with no trailing slash. Bluesky does not check rel="me"; it is there because it is the convention other verifiers look for. {% endcomment %}
